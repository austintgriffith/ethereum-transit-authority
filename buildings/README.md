# Gadget buildings

One building image per gadget for the skyline layout. Generated by
`tools/render-buildings.py` with gpt-image-2, all matching one reference style.

- Files: `<gadget-id>.png` (ids in `data/buildings.json` / `data/categories.json`).
- Spec: square, transparent background, no text, soft shadow, single building.
- To (re)generate once a style is picked: set `style_prompt` in
  `data/buildings.json`, then `python3 tools/render-buildings.py --style ref.png`.
