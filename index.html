None = top priority; painful = still worth fixing; local = the escape hatch already exists. Prevalence is an initial signal, not the final sort — weight later by real transaction volume. Every gadget the centralized flows outsource to a company (a leak you can see), the Mountain Man must run himself — at a cost the map never shows — or it's simply missing (no self-sovereign option today).
